# Medichronicle

Medichronicle is a healthcare management web application that allows users to securely store, manage, and access medical prescriptions and reports. The platform provides a user-friendly dashboard for patients and an admin panel for overseeing records and user interactions.


## Features

- User Authentication – Secure login and signup system with JWT authentication.

- Prescription & Report Upload – Users can upload, view, and manage medical files.

- Dashboard – Personalized dashboard displaying user information and uploaded documents.

- Admin Panel – Admins can manage users and oversee uploaded files.

- Responsive UI – Clean and accessible design with Tailwind CSS for seamless experience.


## Tech Stack

**Frontend:** React.js, Tailwind CSS

**Server:** Node, Express

**Databaser:** MongoDB Atlas

**Authentication:** JWT, Firebase

**Other Tools:** Axios for API calls, Git for version control

## Installation

Clone the repository:

```bash
  git clone https://github.com/shahriar2711/Medichronicle.git
```
Navigate to the project folder:

```bash
 cd Medichronicle
```
Install dependencies:
```bash
  npm install
```
Start the development server:
```bash
  npm start
```
